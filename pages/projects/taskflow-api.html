The project

Task management with secure access.

TaskFlow API lets users register and authenticate, then create, read, update, and delete tasks. JWT-protected routes and admin/user roles demonstrate practical authentication and authorization patterns.

The Flask and SQLAlchemy service includes Swagger documentation so developers can explore and test the API.

What I built

  • Implemented registration and login with JWT-protected routes.
  • Added task CRUD workflows and admin/user role-based access.
  • Documented the API with Swagger (Flasgger).
  • Prepared a Postman collection to exercise the API endpoints.
