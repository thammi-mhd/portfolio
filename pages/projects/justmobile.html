JustMobile.

An e-commerce backend platform for product discovery, cart management, and order workflows.

FlaskPostgreSQLSQLAlchemyREST APIs

The project

Reliable building blocks for an online shop.

JustMobile provides backend services for an e-commerce experience, covering the product catalog, shopping cart, and order flow. It uses Flask and SQLAlchemy with a relational PostgreSQL data store.

The project includes normalized data models, authentication, and role-based permissions, with application entry points designed to support deployment.

What I built

  • Implemented REST endpoints for catalog, cart, and order workflows.
  • Designed relational models with SQLAlchemy and PostgreSQL.
  • Added authentication and role-based access controls.
  • Prepared deployment entry points for production hosting.
